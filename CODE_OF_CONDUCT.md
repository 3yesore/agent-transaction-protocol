# Code of Conduct

This project is a research repository. The most useful thing you can bring is a
concrete counterexample.

## Expected

- Attack the model, not the person. "This fails for input X because Y" is the
  ideal message shape.
- State your assumptions. If you rely on an implementation detail, name it.
- Accept that a rejected idea is a result, not a defeat. Recorded failures are
  how this repository evolves.
- Cite sources for established technical claims.

## Not acceptable

- Harassment, personal attacks, or discriminatory language in any project space.
- Presenting a speculative claim as an established result.
- Marketing language, promotional posting, or off-topic self-promotion.
- Deliberately misrepresenting what an experiment measured.

## Scope

This applies to issues, pull requests, discussions, and any other space where
you are representing the project.

## Enforcement

Report problems to the maintainers listed in the repository. Maintainers may
edit, close, or remove contributions and may block accounts for violations.

This is a short form of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in full where this file is silent.
