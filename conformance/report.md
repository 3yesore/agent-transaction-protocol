# ATP-0002 Conformance Report

Generated by conformance/run.ts.

ATP-0002 reduces to **one substantive rule**: a transition is evaluated under the
semantics in force *before* it, so a semantic change must be authorised by what it
replaces. The kernel otherwise leaves the relation free. A conformance suite for
that claim therefore has to be small: five behavioural probes, one of which is
the rule itself.

Each probe states the ATP-0002 sentence it tests. A target that fails a probe does
not conform.

## Probes

| Probe | Requirement | Expectation |
|-------|-------------|-------------|
| P1-genesis | SPEC 2: D = (S0, R0), an initial semantic state. | the implementation exposes a semantic context at genesis |
| P2-pre-state-evaluation | SPEC 4: the transition that introduces R1 must be recognized under the preceding semantic context R0. | a semantic change that the PRE-state semantics does not authorise is rejected, even when the successor semantics would accept it |
| P3-permitted-evolution | SPEC 4: semantics may itself evolve. | a semantic change that the pre-state semantics DOES authorise is accepted |
| P4-ordinary-transition | SPEC 2: R(S, X, C, S') -> valid / invalid. | an ordinary transition that the semantics in force permits is accepted, so the target is not rejecting everything |
| P5-determinism | SPEC 2: R is a relation; the same state, input, context and successor have one verdict. | two fresh instances given identical inputs return the same verdict |

## What a failure means

- **P2 fails** - the implementation consults the successor's semantics, so a domain
  can adopt rules that authorise their own adoption. This is the whole kernel rule,
  and the mutant that fails only P2 is otherwise identical to the control.
- **P3 fails** - semantic evolution is impossible, which makes P2 vacuous.
- **P4 fails** - the target rejects everything and passes P2 for the wrong reason.
- **P5 fails** - the relation is not a relation; acceptance depends on history rather
  than on the state, input, context and successor.

## Scope

This suite establishes conformance to the **one rule**, not correctness, safety, or
usefulness. A target can pass all five probes and still lose all your money. What it
cannot do is pass and then let a domain rewrite its own semantics.
